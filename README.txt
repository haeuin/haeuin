HAEUINEL PERSONAL WEBSITE — V4

Files:
- index.html
- style.css
- script.js

Open on Android / SPCK:
1. Extract the ZIP into a project folder.
2. Open that folder in SPCK Editor.
3. Open index.html and tap Preview.
4. For GitHub Pages, upload all three files to the repository root.

V4 updates:
- English is the default language; language choices remain English, Indonesian, Malay, Japanese, and Arabic.
- Replaced the central h. mark with a custom penguin-outline emblem and profile details (age 16, West Sumatra, favorite animal).
- Removed the horizontal section navigation and added a morphing floating button that expands into an icon-only section menu.
- Game cards use game-specific image URL candidates with local text fallbacks if images fail. Image links require internet access; the layout remains intact if unavailable.
- Game status is shown with a green dot for OPEN/currently playing and a red dot for CLOSE/no longer playing.
- No framework, backend, or build step is required.

Note: Some game cover URLs are third-party Wikipedia file redirects and may not resolve for every title. The cards include a fallback label so the page layout does not break.
